# HookyMod beta

This is an experimental **pre-release**, not a guarantee of stable operation or
compatibility with any particular game or loader. Back up your own files.

## Installers

- **Linux x86-64:** Debian/Ubuntu `.deb`, built on Ubuntu 24.04. Other Linux
  distributions and older glibc versions have not been validated.
- **Windows x86-64:** NSIS setup executable. The system needs WebView2.
- **macOS:** separate DMG installers for Apple Silicon and Intel. The packaged
  backend is exercised with synthetic fixtures; the macOS window has not been
  tested interactively by this CI.

These builds are **not signed** and the macOS builds are **not notarized**.
Windows SmartScreen or macOS Gatekeeper may warn or prevent opening them. Only
install binaries you trust; signed and notarized packages need separate setup.
Use `SHA256SUMS.txt` to check the downloaded files against this release.

## Files, rights and limitations

included. Supply only files you have the right to use. Exports and assembled
mods may contain original or derivative input material: check your rights before
sharing outputs. The retained project logo's origin and rights remain unverified.

Project material is offered under the noncommercial HookyMod license where the
rights holders can grant it; genuine voluntary donations without benefits are
allowed. Third-party components keep their own licenses and prior rights are
not revoked. Known notices are included, but **the inventory of dependencies
and redistribution obligations in standalone binaries is not complete**. Review
those obligations, contributors' rights and the logo before wider distribution.
