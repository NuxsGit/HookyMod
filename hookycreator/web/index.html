Que veux-tu créer ?

Un mob, une nouvelle peau, un modèle retouché dans Blender : tout finit dans un dossier mods/ prêt à charger.

Tout exploiter

Décode toutes les textures en PNG et exporte tous les modèles (glTF + OBJ), y compris ceux qui sont dans les packs .pack.zs. Un rapport liste ce qui a réussi et ce qui ne l'a pas été.

    Textures

    Clique une texture pour la prévisualiser et remplacer son contenu.

    Modèles

    Aperçu rendu côté serveur dans le budget mémoire choisi, puis export glTF/OBJ pour Blender.

    Réglages

    Le budget mémoire évite de faire tomber la machine sur un gros modèle : 6 Go par défaut, réglable jusqu'à 25 Go. Le rendu se dégrade avant de refuser.

    Budget mémoire

    6 Go
    1 Go25 Go

    Au-delà de ce budget, l'anticrénelage baisse, puis le nombre de faces dessinées est limité, et si rien ne rentre l'aperçu est refusé avec les chiffres exacts.

    Qualité et culling

    ×2

    Plafond de faces

    auto

    0 = automatique (le budget décide). Un plafond explicite rend les aperçus de très gros modèles plus rapides, au prix d'une image partielle : c'est écrit dans le panneau du modèle.
